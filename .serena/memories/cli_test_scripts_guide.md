## 🐛 既知の制限事項

### 1. 時間制限
- 分配機能は30日間隔が必要
- Testnetでは実際の時間経過が必要
- 回避策: ボーナス分配機能を使用

### 2. USDCコイン
- 実際のTestnet USDCが必要
- テスト用にSUIコインを使用可能（デモ用）
- 回避策: SUIコインを分割して使用

### 3. 複数アドレス
- 現在のアクティブアドレスのみテスト可能
- 別のアドレスをテストするには切り替えが必要
- 回避策: `sui client switch --address`で切り替え

### 4. 並行実行
- 複数のスクリプトを同時に実行すると競合する可能性
- 回避策: 1つずつ実行

## 📚 参考コマンド

### Sui CLI基本コマンド
```bash
# アドレス一覧
sui client addresses

# アドレス切り替え
sui client switch --address <ADDRESS>

# オブジェクト確認
sui client object <OBJECT_ID>

# ガス残高確認
sui client gas

# トランザクション実行
sui client call --package <PKG> --module <MOD> --function <FUNC> --args <ARGS>
```

### jqコマンド例
```bash
# JSONから特定のフィールドを抽出
sui client object <ID> --json | jq '.data.content.fields'

# 配列をフィルタ
sui client objects --json | jq '.[] | select(.data.type | contains("MemberNFT"))'
```
